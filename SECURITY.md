# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities **privately** — do not open a public issue
or discuss the problem in public before a fix is available.

Use GitHub's private vulnerability reporting: open the repository's **Security**
tab and click **"Report a vulnerability"** to file a private security advisory.
This reaches the maintainers directly and keeps the details confidential while a
fix is prepared.

Please include enough detail to reproduce the issue (affected version, a minimal
reproduction, and the impact). We will acknowledge your report, investigate, work
on a fix, and coordinate disclosure with you.

## Supported versions

gatekit-automa is pre-1.0; fixes are released against the latest published
version.
